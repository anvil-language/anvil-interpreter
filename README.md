# anvil-interpreter

A simple go written interpreter built for Linux and windows for the anvil language.

# Dependency's

As of current the only tool/dependency that is required is go. you can [find go here](https://go.dev). This comes with the runner, compiler and tester for 
the code in this repository.

# Building

To build all you need to do on linux and on windows is the following. 
```sh
go build -o bin/anvil ./cmd/anvil
```
Then running is as simple as typing `./bin/anvil` to access the repl.
